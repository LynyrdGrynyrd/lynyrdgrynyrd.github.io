## AI coding agents

- [OpenCode](https://github.com/anomalyco/opencode) - Open-source coding agent for the terminal.
- [OpenHands](https://github.com/OpenHands/OpenHands) - AI-driven software development platform.
- [goose](https://github.com/aaif-goose/goose) - Extensible open-source agent that installs, runs, and tests code.
- [Orca](https://github.com/stablyai/orca) - Run a fleet of coding agents on your own subscriptions.
- [LLM Council](https://github.com/karpathy/llm-council) - Several models answer, review each other, and agree on an answer.
- [Fabric](https://github.com/danielmiessler/Fabric) - Modular prompts for everyday AI tasks.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) - Personal agent that learns as you use it.

## Claude Code skills and add-ons

- [Matt Pocock's skills](https://github.com/mattpocock/skills) - Practical engineering skills for coding agents.
- [Impeccable](https://github.com/pbakaus/impeccable) - Design vocabulary so your agent builds better UI.
- [Ponytail](https://github.com/DietrichGebert/ponytail) - Makes your agent write the least code that works.
- [Stop Slop](https://github.com/hardikpandya/stop-slop) - Removes AI tells from prose.
- [Karpathy skills](https://github.com/multica-ai/andrej-karpathy-skills) - One CLAUDE.md based on Andrej Karpathy's coding advice.
- [improve](https://github.com/shadcn/improve) - A strong model audits your code and writes plans for cheaper models.
- [cad-skill](https://github.com/flowful-ai/cad-skill) - Parametric, 3D-printable models with CadQuery.
- [Awesome Agent Skills](https://github.com/VoltAgent/awesome-agent-skills) - 1,000+ agent skills in one list.
